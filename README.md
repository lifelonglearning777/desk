# SAYAKA'S DESK — GitHub Pages Edition

個人用の自作アプリランチャーです。

## 通常表示
`https://ユーザー名.github.io/リポジトリ名/`

## 編集モード
URLの末尾に `?edit=1` を付けます。

例：
`https://ユーザー名.github.io/リポジトリ名/?edit=1`

編集モードでは各カードをクリックすると、アプリ名・説明・URL・カテゴリ・色・アイコンを変更できます。
アイコンは Lucide のアイコン名を指定するか、自分の画像をアップロードできます。

## 保存について
編集内容はブラウザの localStorage に保存されます。同じURLでも別PC・別ブラウザには自動では移りません。
編集画面の「書き出し」でJSONを保存し、「読み込み」で別端末に移せます。

## 画面設計
1366×768クラスの画面で24個を原則1画面に収めることを優先しています。
狭い画面では自動的に4列・2列表示へ切り替わります。

## GitHub Pages
このフォルダをそのままGitHubリポジトリへアップロードし、Settings → Pages から公開してください。
